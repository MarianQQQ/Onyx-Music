Transparency & Trust

Requirements & Technical Notes.

Full transparency on system dependencies, binary signatures, and plugin architecture before you download.

Windows 10 / 11 & WebView2

Requires 64-bit Windows 10 (Version 1809+) or Windows 11. Onyx utilizes the Microsoft Edge WebView2 Evergreen runtime, which is pre-installed on modern Windows systems.

x64 Native Architecture

SmartScreen & Unsigned Binaries

Onyx is 100% open-source and built transparently on GitHub without an expensive commercial EV certificate. Windows Defender SmartScreen may display an "Unknown Publisher" warning on first launch. Click "More info" → "Run anyway".

100% Auditable GitHub Builds

Native Audio & Stream Dispatch

Audio streams are extracted via native Rust IPC and rendered through the Web Audio API / WASAPI 24-bit direct audio pipeline with dual-slot gapless crossfade.

Direct WASAPI · 48 kHz / 24-Bit

Last.fm Keys & Local Storage

The built-in Last.fm scrobbler uses your own free personal API keys (obtainable at last.fm/api). Login cookies and cache remain strictly on your machine in %LOCALAPPDATA%.

Zero Intermediate Cloud Servers
