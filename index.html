Architecture

The Four Pillars of Onyx.

Everything you wished official YouTube Music had, built with zero compromises.

Native Audio Pipeline & Hardware Crossfade

Dual-slot gapless audio engine with configurable 0–12s crossfade between tracks. Direct WASAPI output, 3-band parametric equalizer, and real-time pitch-preserving playback speed regulation (0.5x – 2.0x).

Web Audio API · WASAPI 24-Bit

Virtual Windowing

Scroll through massive 3,000+ track playlists at 120 FPS. Only ~35 DOM rows exist in memory at any millisecond.

120 FPS · 0ms Stutter

Interactive Synced Lyrics

Sub-millisecond synced karaoke lyrics with auto-scroll. If timing drifts, press Alt + Click on any line to instantly calibrate offset in real-time.

LRCLIB · 1-Click Calibration

Built-In Plugin Ecosystem

Includes SponsorBlock to automatically skip music video intros, outros, and speech. Real-time Last.fm scrobbler, Discord Rich Presence displaying current album art, and native Windows notifications.

SponsorBlock · Last.fm · Discord RPC
